# 🍎 FruitVision: Complete Project Guide & Architecture

Please refer to the root document: [PROJECT_GUIDE.md](file:///f:/Antig%20projects/PROJECT_GUIDE.md)

This project contains the full implementation of FruitVision, an AI-powered food vision assistant that detects multiple fruits from real-world photos, counts them, and calculates precise calorie and macronutrient breakdowns in a clean minimalist interface.

### Quick Start:
- To start the application with 1 click, double-click [START_FRUITVISION.bat](file:///f:/Antig%20projects/START_FRUITVISION.bat) in the root directory.
- Open [http://127.0.0.1:8501](http://127.0.0.1:8501) in your browser.
